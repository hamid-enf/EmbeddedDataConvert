# نمونه پارسر جریانی پورت سریال (UART Streaming Parser)

این مثال نحوه دریافت بایت‌به‌بایت داده‌ها از پورت‌های سریال (UART, RS485, USB-CDC, SPI, CAN) و استخراج فریم‌های معتبر پروتکل بدون نیاز به ذخیره بسته‌های ناقص در حافظه را نشان می‌دهد.

## ویژگی‌ها:
* تشخیص خودکار شروع فریم (`start_byte`) و پایان فریم (`end_byte`).
* نادیده گرفتن نویزهای خط سریال بدون ایجاد اختلال در بافر.
* استفاده از بافر ایستا با ابعاد دلخواه کاربر.
* بدون وابستگی به وقفه‌ها یا سیستم‌عامل.

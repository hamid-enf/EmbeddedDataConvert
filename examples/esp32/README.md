# نمونه کد ESP32 برای کتابخانه EDC

این مثال نحوه استفاده از کتابخانه **EmbeddedDataConvert** در پروژه‌های ESP32 و ESP-IDF / FreeRTOS / PlatformIO را نشان می‌دهد.

## مراحل استفاده در ESP-IDF:
1. کتابخانه را در پوشه `components/edc` قرار دهید یا مسیر `include/` و `src/` را در `CMakeLists.txt` کامپوننت خود اضافه کنید.
2. هدر `#include "edc.h"` را اضافه کرده و استفاده نمایید.

## قابلیت‌های پیاده‌سازی شده در این مثال:
* پردازش بسته‌های داده IoT، پیام‌های پروتکل MQTT و فرمت‌های Key-Value با برش حافظه بدون کپی (Zero-Copy).
* تبدیل واحدهای فیزیکی سنسورها (دما به فارنهایت و سلسیوس، فشار پاسکال به بار).
* تبدیل نویسه‌گردانی (Transliteration) پیام‌های هشدار فارسی به فینگلیش برای ارسال از طریق مودم‌های GSM و پیامک‌های ۷ بیتی ASCII استاندارد.

# نمونه کاربردی ردیاب GPS و تله‌متری خودرو (GPS Tracker)

این مثال نحوه ساخت یک سامانه ردیاب خودرو و مدیریت داده‌های ناوبری GNSS با استفاده از کتابخانه **EmbeddedDataConvert** را نشان می‌دهد.

## امکانات:
* پردازش داده‌های زنده ماژول‌های GNSS (مانند Quectel, SIMCom, u-blox).
* پشتیبانی از پروتکل‌های چندمنظوره GPS/GLONASS/Galileo ($GPGGA, $GPRMC, $GNGGA, $GNRMC).
* اعتبارسنجی خودکار Checksum بایت به بایت.
* تبدیل مختصات به فرمت درجه اعشاری (Decimal Degree) و فرمت درجه-دقیقه-ثانیه (DMS).
* تبدیل واحدهای سرعت و ارتفاع.
* فرمت‌دهی گزارش پیامکی فارسی با اعداد فارسی.
